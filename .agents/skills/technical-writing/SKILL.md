# Technical writing

Write repository-authored engineering prose in English. Use the real file, symbol, command, and role names from the codebase.

- Put the purpose and result first.
- Use short, direct sentences. Name the actor when it matters.
- Keep a document focused on one reader task or one topic.
- Use numbered lists for procedures and bullets for unordered items.
- Distinguish verified facts, inference, and unknowns. Put each claim near its evidence.
- Include exact commands and observable results when documenting validation.
- Keep examples consistent with current repository policy and current code.
- Remove repeated, stale, or speculative text instead of restating it.

Repository instructions and the active JIT define policy. Documentation cannot grant a capability, change a safety boundary, or substitute for test, review, CI, or merge evidence.
