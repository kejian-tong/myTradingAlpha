# sharpen

Before work begins, frame the task as an expert would. Identify the result the user wants, the relevant source material and methods already available, and whether the request leaves a material choice or an important constraint unclear. Tighten only what helps the stated goal. Keep choices that belong to the user open.

Retain one authorized outside check that can independently confirm the result. Keep it within the user's request, repository policy, current JIT scope, and available evidence. Do not invoke an external system or expand the scope to create a check. If no outside check is authorized and available, state that evidence gap and use the permitted repository checks.

Do not weaken or loosen policy, JIT, scope, compatibility, authorization, or human gates. Sharpening a task adds no authority, waives no approval, and cannot change the work the user authorized. Proceed only under the original request and its existing gates.
