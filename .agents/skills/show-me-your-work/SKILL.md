# Show me your work

Use this skill to make an engineering result easy to inspect. Build the account from existing PR, JIT, Git, CI, and review evidence, including focused test and writer-lease results when they apply.

For each important decision or result, point to the file, commit, command output, PR record, or CI check that supports it. State the exact result and distinguish completed evidence from pending gates. Keep the summary within the task's authorized scope.

Do not read raw transcripts. Do not copy raw prompts, credentials, user data, or private identifiers. Do not create a private log or another decision record when the active PR and repository artifacts already hold the evidence. If the required evidence is absent, say that it is absent instead of reconstructing it from memory.
