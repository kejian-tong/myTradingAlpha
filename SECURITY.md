# Security Policy

## Project status

myTradingAlpha is currently a research-only project. It does not provide a live trading service. The
maintainer evaluates reports against the current `main` branch and released tags case by case; no
blanket support window is promised.

## Reporting a vulnerability

Please report security vulnerabilities through [GitHub's private vulnerability reporting
form](https://github.com/kejian-tong/myTradingAlpha/security/advisories/new). This is the project's
sole vulnerability reporting channel. Do not disclose vulnerability details in public issues,
discussions, or pull requests.

Include a sanitized reproduction with the affected commit or tag, steps to reproduce, and observed
impact. Use synthetic or redacted examples. Do not include real credentials, API keys, broker or
account identifiers, account information, or trading data.

The maintainer will assess reports case by case and may request additional sanitized details. Public
disclosure should be coordinated with the reporter after a fix is available.
