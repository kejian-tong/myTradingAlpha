# myTradingAlpha

`myTradingAlpha` is an independently maintained derivative project based on the open-source [TradingAgents](https://github.com/TauricResearch/TradingAgents) project originally developed by [TauricResearch](https://github.com/TauricResearch).

This repository uses its own Git history and is maintained independently from the upstream project. It contains modifications and extensions relative to the upstream source.
