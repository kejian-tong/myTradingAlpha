# Productionization History

This directory is optional cold history for operational recovery material that no longer belongs in the
current `AGENT_STATE.md` snapshot but remains useful to retain in-repository.

GitHub PR conversations, commits, reviews and workflow records are the primary durable evidence. Do not
copy entire PR transcripts here, and do not create an archive when an immutable GitHub reference is
sufficient.

When an archive is justified:

- name it by topic/phase and date rather than by a mutable "latest" label;
- preserve factual SHAs/PR IDs and mark superseded claims explicitly;
- keep resolved chronology separate from active blockers/current authorization;
- never treat an archive as automatically loaded execution policy or current authority.

The current state file should point to an archive only when a fresh master needs that specific historical
context to understand a surviving decision or recovery boundary.
